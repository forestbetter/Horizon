### [Telegram 小组件被指存在远程代码执行漏洞](https://x.com/telegram/status/2120502876728680765?a=qTsR6dLMSgt3RHbYYO0&amp;amp;s=46) ⭐️ 8.0/10

社区发布安全提醒称，Telegram Widgets 存在沙箱逃逸漏洞，可导致远程代码执行。该功能由 Telegram 在 2026 年 11 月 9 日发布的 Bot API 10.4 中引入，允许机器人在聊天消息内嵌入 HTML、CSS 和 JavaScript 以构建交互式界面，而 JavaScript 在客户端沙箱中运行正是漏洞所在。提醒者建议用户不要点击来路不明的机器人，并暂时不要升级到支持 Telegram Widgets 的版本。Telegram 官方表示漏洞已修复，但据群友测试，在部分设备的最新版本上该漏洞依然可用。该提醒为简短社区消息，未提供漏洞编号、影响版本范围或复现细节，相关说法尚待进一步验证。

telegram · zaihuapd · 11月13日 09:02

**「背景」** Telegram Widgets 是 Telegram 在 2026 年 11 月 9 日发布的 Bot API 10.4 中引入的功能，机器人可通过 sendWidget 方法在聊天消息内嵌入小型交互式 HTML 块，其中可包含 HTML、CSS 和 JavaScript，从而在消息中实现计算器、游戏等交互界面。由于这些 JavaScript 运行在 Telegram 客户端内，客户端需要依赖沙箱机制隔离其执行环境；本次社区警报所指的正是该沙箱实现可能存在逃逸风险。

**「影响」** 使用支持 Telegram Widgets 的客户端用户面临来自恶意机器人消息的零点击远程代码执行风险，官方称已于 11 月 11 日修复、11 月 12 日全量推送，但社区测试称部分设备最新版本仍可利用，建议暂勿点击来路不明的机器人消息并谨慎升级。

### [Python 早期贡献者 Tim Peters 去世，享年 74 岁](https://x.com/Itsfoss/status/2120957452937998716) ⭐️ 7.0/10

Python 创造者 Guido van Rossum 宣布，Python 社区早期贡献者 Tim Peters 去世，享年 74 岁。Peters 是 Python 的第二位真实用户，也是 Timsort 排序算法的作者，并撰写了《Python 之禅》（PEP 20）。他还在 Python 软件基金会（PSF）董事会任职 13 年。

**「背景」** 《Python 之禅》（PEP 20）是 Python 官方增强提案中的第 20 号条目，已被发布到公有领域，并以彩蛋形式内置于 Python 解释器中，输入 import this 即可显示。Tim Peters 于 2002 年设计了 Timsort 排序算法，用于 Python 列表排序，该算法后来也被 Java 和 Android 采用。

**「影响」** Peters 的贡献横跨语言设计理念、核心算法与社区治理，其离世对 Python 社区而言是重要损失。
