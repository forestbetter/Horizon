### [CoreWeave 2032 年债券收益率突破 16%，AI 数据中心债务风险升温](https://www.cnbc.com/2026/11/06/coreweave-bond-yield-tops-16percent-as-ai-credit-stress-rises.html) ⭐️ 8.0/10

据 CNBC 报道，CoreWeave 票面利率 9.625%的 2032 年债券收益率已升至 16%以上，其五年期信用违约互换（CDS，即违约保险成本）周四一度超过 1289 个基点，周五回落约 8%至 1155 个基点附近。

**「背景」** 投资者担心俄亥俄、得州和佐治亚等关键州新当选的民主党州长可能对数据中心设限，高盛估算相关暂停令可能影响美国约 45%的规划产能；同时，高盛预计超大规模云厂商明年将发行 4400 亿美元债券，另有 3000 亿美元项目级发行。

**「影响」** CDS 走阔意味着英伟达、博通、亚马逊等大型发行人的未来融资成本可能上升，而 CoreWeave 等新型云厂商若资本开支收缩，可能面临合同减少或预付款延迟。

**「影响」** 若美联储继续加息，美国居民和企业的借贷成本（如信用卡、汽车贷款和商业贷款）可能进一步上升；但戴利强调的是政策方向而非已定决策，具体节奏仍取决于后续数据。

### [Claude Code 被指联网时泄露登录邮箱](https://github.com/anthropics/claude-code/issues/107757) ⭐️ 7.0/10

有开发者投诉称，Claude Code 在联网搜索时会擅自把用户的登录邮箱填入网络请求并发送，导致其每天收到大量诈骗邮件。Anthropic 工程师解释，此前为解决 Claude 乱填作者名的问题，才把登录邮箱放进了模型上下文。该问题今年 7 月已有人报告，邮箱被发送至 Wikipedia、美国证券交易委员会等站点；2.1.317 版已加入拦截，但据称可被 Python 脚本绕过，公司计划在下一版本中从模型上下文移除登录邮箱。上述说法来自开发者投诉与 Telegram 频道转述，底层 GitHub issue 未在此得到独立核实，实际影响范围尚不明确。

telegram · zaihuapd · 11月7日 16:09

**「背景」** Claude Code 是 Anthropic 推出的命令行 AI 编程助手，可在开发环境中执行任务并联网搜索。据公开的 GitHub issue 107757 描述，该工具在联网搜索时会把用户账号邮箱写入 HTTP 请求的 User-Agent 头，发送给第三方网站。Anthropic 工程师解释，这一做法最初是为了解决 Claude 在填写作者名时乱填的问题，才将登录邮箱放入模型上下文。

**「影响」** 使用 Claude Code 联网搜索功能的开发者可能已将登录邮箱暴露给 Wikipedia、美国证券交易委员会等第三方站点，从而面临定向诈骗邮件风险；2.1.317 版的拦截可被 Python 脚本绕过，在下一版本移除上下文邮箱前，相关用户仍需保持警惕。
