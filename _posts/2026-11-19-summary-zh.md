### [Xint 披露 5 个 nginx 漏洞，可提权至主机 root](https://nginx2root.com/) ⭐️ 7.0/10

Xint 公开了名为 NGINX2Root 的漏洞利用链，由 5 个 nginx 漏洞与一个 Linux 内核缺陷串联而成，可从 nginx 访客身份一路提权至主机 root。其中 CVE-2026-123007 是 HTTP/2 流控内存破坏漏洞，未认证攻击者即可在 worker 进程中执行命令。nginx 1.30.7 与 1.31.9 已于 11 月 18 日修复共 10 个 CVE，Rapid7 已放出 PoC，目前暂无在野利用报告。无法升级的用户需关闭对外 HTTP/2 以规避风险。

telegram · zaihuapd · 11月19日 00:21

**「背景」** nginx 是广泛部署的开源 Web 服务器与反向代理，常以 worker 进程处理请求，并常运行在容器或受限权限下。Xint 将五个 nginx 漏洞与一个 Linux 内核缺陷串联，形成从 nginx 访客到主机 root 的攻击链，其中 CVE-2026-123007 涉及 HTTP/2 流控内存破坏，未认证即可在 worker 中执行命令。根据 Xint 的说明，该组合在 nginx 运行于 Docker 容器的环境中也能取得主机 root shell，部分 Linux 发行版默认安装并自动加载 SCTP 模块，可能扩大攻击面。

**「影响」** 运行受影响 nginx 版本且对外启用 HTTP/2 的服务器面临未认证远程代码执行风险，攻击者可先以 worker 权限执行命令，再结合内核缺陷提权至主机 root；无法立即升级的部署应关闭对外 HTTP/2 作为缓解措施。
