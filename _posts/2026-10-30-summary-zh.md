### [Cursor 市场 Claude Code 插件遭投毒](https://cursor.com/blog/claude-code-extension-security-notice) ⭐️ 8.0/10

Cursor 发布安全公告称，10 月 29 日 OpenVSX/VS Code 扩展市场中出现了被篡改的 Anthropic.claude-code 2.1.313 版本，该版本并非 Anthropic 开发，最多约 5000 名用户受影响。该扩展会收集主机信息，并试图植入长期 SSH 后门；由于建立隧道需要管理员权限，多数主机上的尝试失败。Cursor 已下架该版本、暂时关闭整个扩展市场，并在轮换密钥后重新上线，攻击者服务器也已下线。

telegram · zaihuapd · 10月30日 16:44

**「背景」** OpenVSX 是一个开源的 VS Code 扩展市场，Cursor 等基于 VS Code 的编辑器可从中获取扩展，因此其上的扩展包一旦被篡改，会直接分发到使用这些编辑器的开发者机器上。Claude Code 是 Anthropic 推出的 AI 编程工具，其 VS Code 扩展以 Anthropic.claude-code 为标识发布。此次事件中，攻击者以该扩展的 2.1.313 版本为载体植入恶意代码，属于典型的软件供应链投毒。

**「影响」** 使用 Cursor 及 OpenVSX 扩展市场的开发者需立即核查是否安装过 Anthropic.claude-code 2.1.313，并检查主机是否存在异常 SSH 隧道或凭据泄露风险。

### [FCC 投票禁止中国实验室检测输美电子设备](https://www.reuters.com/business/media-telecom/fcc-votes-ban-all-chinese-labs-testing-us-electronics-2026-10-29/) ⭐️ 7.0/10

美国联邦通信委员会（FCC）于 10 月 29 日投票通过新规，禁止所有中国实验室为智能手机、相机、电脑等输美电子设备进行检测认证，新规将于 2028 年 12 月生效。FCC 主席 Brendan Carr 表示，2025 年有 82%的电子产品在中国检测，而美国本土检测仅约 4%，并指出中美之间没有检测互认协议。该决定是对 2025 年限制中国政府所属实验室措施的进一步扩大，将影响面向美国市场的硬件制造商和进口商的合规路径。

telegram · zaihuapd · 10月30日 11:15

**「背景」** 美国联邦通信委员会（FCC）负责对进入美国市场的无线电和电子设备实施认证管理，设备须通过其认可的实验室检测后才能获得认证。此前，FCC 已于 2025 年出台规定，限制中国政府所属实验室参与相关检测；本次投票是在此基础上的进一步扩大。据 FCC 主席 Brendan Carr 所述，2025 年有 82% 的电子产品在中国完成检测，而中国与美国之间并无检测互认协议，美国本土检测占比仅约 4%。

**「影响」** 依赖中国实验室完成 FCC 认证的硬件厂商和进口商需在 2028 年 12 月前将检测转移至其他地区，否则相关电子产品可能无法取得进入美国市场的认证。
