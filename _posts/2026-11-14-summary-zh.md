### [谷歌高管演示折叠 iPhone 本地运行 Windows 11](https://www.windowslatest.com/2026/11/14/windows-11-can-run-on-apples-foldable-iphone-and-googles-ai-boss-proved-it-using-gemini-years-after-microsoft-gave-up-on-windows-phones/) ⭐️ 7.0/10

据 Telegram 转述的 Windows Latest 报道，Google AI Studio 产品设计负责人 Ammaar Reshi 使用 Gemini 4 Carbon，让 Windows 11 24H2 在苹果折叠手机 iPhone Duo 上本地运行，并公开了操作视频。演示依赖开源项目 WindowsiOS，无需越狱，通过 JIT 翻译执行 ARM64 代码，并支持微软 Prism 运行部分传统应用。镜像体积约 12 GB，运行环境需要 Apple Silicon Mac 与相应开发工具。该消息目前仅来自单一 Telegram 帖文对 Windows Latest 的转述，Gemini 模型名称与设备命名均未获独立核实，实际可用性和性能尚不明确。

telegram · zaihuapd · 11月14日 14:52

**「背景」** Windows 11 官方仅支持 x86-64 架构，而苹果 iPhone 采用 ARM64 架构，因此要在 iPhone 上运行 Windows 11，必须依赖指令集翻译或虚拟化层。JIT（即时编译）翻译是一种在运行时把 ARM64 指令动态转换为可执行代码的技术，常被用于跨架构模拟；微软自家的 Prism 则是 Windows on ARM 上用于运行传统 x86 应用的兼容层。Ammaar Reshi 是 Google AI Studio 的产品设计负责人，此前曾公开展示用 Gemini 模型快速构建应用与游戏。

### [Cloudflare 开源 AI 代理浏览器 Kitesurf](https://www.phoronix.com/news/Cloudflare-Kitesurf-Open-Source) ⭐️ 7.0/10

Cloudflare 以 Apache 2.0 协议开源了面向 AI 代理的无状态浏览器 Kitesurf，代码已发布在 GitHub。Kitesurf 基于 Cloudflare Workers 构建，无需浏览器容器即可解析 HTML、处理 CSS 并执行 JavaScript。Cloudflare 表示，其目标是给 AI 代理提供一个轻量、高效的浏览器，相比 Chromium 占用更少 CPU 和内存，并能在全球 Workers 网络上按需扩展。上述性能与扩展性说法来自 Cloudflare 自身表述，目前尚无独立验证。

telegram · zaihuapd · 11月14日 17:33

**「背景」** AI 代理通常需要访问网页来获取信息或执行操作，传统做法是借助 Chromium 等无头浏览器完成页面渲染与脚本执行，但这类方案资源开销较大。Cloudflare 在 Agents Week 期间推出实验性浏览器引擎 Kitesurf，将其定位为面向 AI 代理的轻量替代方案，并已在 Cloudflare Workers 上提供测试版。

**「影响」** 对于在 Cloudflare Workers 上构建 AI 代理的开发者，Kitesurf 提供了一种无需浏览器容器的无状态替代方案，目前处于 beta 阶段，可在 Browser Run 中免费使用。Cloudflare 声称，在截图和 HTML 提取等常见代理任务中，它比 Chromium 少用 3 至 7 倍 CPU 和内存，但这些性能数据尚未得到独立验证。
