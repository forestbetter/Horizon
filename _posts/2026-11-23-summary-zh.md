### [codex2api 疑遭供应链投毒 3.1.10–3.1.12 含后门](https://github.com/WormW/codex2api-incident-2026-11) ⭐️ 8.0/10

据 Telegram 频道 zaihuapd 转述的事件复盘，codex2api 作者账号疑似被入侵，攻击者绕过 main 分支直接推送 tag，使 Release 构建出带后门的版本。受影响版本为 v3.1.10–v3.1.12，其中 v3.1.11 移除了鉴权，等同于可无密码远程执行命令；同时有 workflow 将仓库的 16 个 Actions secrets 外传，波及同一账号下至少 21 个仓库。报告建议已安装或更新至 3.1.10–3.1.12 的用户立即停用并回退到 3.1.9，同时轮换 GitHub token、SSH key、数据库及 DeepSeek 等相关密钥。上述细节来自 Telegram 帖子引述的事件复盘，尚未见独立验证。

telegram · zaihuapd · 11月23日 19:21

**「背景」** 供应链投毒指攻击者入侵开源项目维护者账号或构建流程，在正式发布的软件包或二进制中植入后门，使下游用户在正常安装更新时中招。GitHub Actions 的 workflow 通常持有仓库 secrets（如 token、SSH key、数据库口令），一旦被恶意 workflow 读取即可外传，并可能横向影响同一账号下的其他仓库。此类事件在 2026 年已多次出现，例如 LiteLLM 在 PyPI 与 Docker 渠道的两次供应链入侵。

**「影响」** 已安装或更新至 v3.1.10–v3.1.12 的用户应立即停用并回退到 3.1.9，同时轮换 GitHub token、SSH key、数据库及 DeepSeek 等相关密钥；由于恶意 workflow 已外传 16 个 Actions secrets 并波及同账号下至少 21 个仓库，凡该工作流可触达的仓库、组织级 secret、变量与云凭证都应视为已泄露。

### [谷歌搭建模拟互联网测试 Chrome AI 代理](https://www.landian.news/archives/128701.html) ⭐️ 7.0/10

谷歌为 Chrome 的 AI 代理搭建了一个名为 Mirror Dimension 的模拟互联网，在隔离环境中测试其打开网站、搜索浏览、登录、加购和完成任务等操作。据蓝点网报道，该环境包含数千个模拟网站，每名工程师单独隔离测试，每天运行超过 1000 个测试案例，重点防御恶意网页的提示词注入等攻击。这一做法将代理式浏览器自动化的安全验证放在可控的仿真环境中进行，而非直接暴露于真实网络。相关细节来自二手来源的简要转述，具体实现方式和测试结果尚未得到谷歌官方确认。

telegram · zaihuapd · 11月23日 09:30

**「背景」** 浏览器 AI 代理能够代替用户打开网页、点击按钮、填写表单并完成多步骤任务，但这也意味着恶意网页可能通过提示词注入等方式诱导代理执行非预期操作。为在不影响真实网站和用户的前提下评估这类风险，谷歌 Chrome 团队构建了名为 Mirror Dimension 的合成互联网环境，作为隔离沙箱来训练和测试浏览代理。据谷歌 Chrome AI 安全团队介绍，该环境旨在以贴近真实的在线场景安全测试代理，避免产生现实世界中的安全风险。

**「影响」** 对开发浏览器 AI 代理的团队而言，Mirror Dimension 这类可合成恶意载荷、并在任意页面位置注入的隔离评测环境，为在部署前量化代理抵御提示词注入的能力提供了可复用的测试思路。不过该环境目前服务于谷歌内部 Chrome 代理测试，外部团队能否直接使用尚不明确。

### [开源工具 nospeaker 用触控板振动发声念文字](https://m.mydrivers.com/newsview/1167826.html?ref=https%3A//www.google.com/) ⭐️ 7.0/10

开发者 Cody Collier 开源了工具 nospeaker，利用 MacBook 触控板下方的触觉马达以每秒 4000 次的频率驱动，使玻璃振动快到人耳可闻，从而“念出”文字。该工具通过 macOS 语音合成读入文本，每 10 毫秒提取两个共振峰，并连同响度与音高一起重放，听感偏机器人化。实测在 100 Hz 至 4 kHz 范围内可发声，1 kHz 附近最清晰。它只能朗读文字，无法播放音乐或视频，并且绕开苹果公开的触觉接口，调用私有框架 MultitouchSupport。使用需配备 Force Touch 触控板，作者称目前仅在 M5 Max 的 MacBook Pro 上验证通过。

telegram · zaihuapd · 11月23日 15:16

**「背景」** MacBook 的 Force Touch 触控板内置触觉马达，原本用于模拟点击等触感反馈，苹果通过公开 API 限制其用途。nospeaker 借助私有框架 MultitouchSupport 直接控制该马达，以高频振动产生可听声音，属于对硬件能力的逆向利用。

**「影响」** 对拥有 Force Touch 触控板 MacBook 的开发者而言，这提供了一种无需额外扬声器即可发声的实验性方案，但依赖私有 API 且仅在单一机型验证，兼容性与稳定性尚不确定。

**标签**: `#haptics`, `#open-source`, `#macOS`, `#accessibility`, `#reverse-engineering`
