### [谷歌发布 Gemini Decisions API 快速多模态决策](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/) ⭐️ 7.0/10

谷歌发布 Gemini Decisions API，基于新模型 Gemini Decision 1，面向工具选择、策略检查和模型路由等封闭式决策任务。该 API 支持文本、图像、音频、视频和 PDF 输入，单次最多可对 1000 个问题打分，并返回概率与置信度，端到端延迟约为 150-250 毫秒。定价为每百万输入 tokens 0.10 美元，输出 token 不收费，据称比 Gemini 3.5 Flash-Lite 方案便宜近 5 倍。该 API 现已在 Google AI Studio 提供。上述延迟、价格和成本对比均为谷歌方面的说法，尚未见到独立验证。

telegram · zaihuapd · 11月12日 08:28

**「背景」** Gemini 是谷歌推出的大模型系列，谷歌通过 Google AI Studio 等开发者平台向外部提供模型调用能力。在智能体（agent）系统中，工具选择、策略检查和模型路由等环节通常需要模型做出封闭式判断，即从有限选项中选出答案，而非生成开放式文本。这类任务对响应速度和单次调用成本较为敏感，因此业界出现了针对此类场景优化的专用模型与 API。

**「影响」** 对需要频繁进行工具选择、策略检查或模型路由的开发者而言，该 API 以约 150-250 毫秒延迟和每百万输入 tokens 0.10 美元、输出不收费的定价，提供了比通用模型方案更低成本、更专用的封闭式决策路径。

### [苹果详解 Secure Exclaves：硬件验证录音指示灯防遮挡](https://security.apple.com/blog/secure-exclaves/) ⭐️ 7.0/10

苹果于 11 月 12 日发布文章，详解其 Secure Exclaves（安全隔离区）架构。该架构在独立安全环境中处理音视频，使主系统及 App 在环境感知模式下仅获取必要的识别结果，避免接触原始数据。该技术已应用于 HomeView 的人脸与声音识别，以及 iPhone 18 Pro 的隐私指示器。在 iPhone 18 Pro 上，专用硬件会验证麦克风指示点的颜色、亮度及可见性，确认符合要求后才允许音频进入主系统。苹果还要求相关 Siri 音频会话期间持续显示指示点，且总显示时间至少三秒，以防止指示点被遮挡或伪装。

telegram · zaihuapd · 11月12日 17:13

**「背景」** 苹果此前已通过 Secure Enclave 处理器保护密钥等敏感数据，但该组件并非独立芯片，而是集成在 SoC 中的安全子系统。近年苹果进一步调整 XNU 内核结构，引入 Secure Kernel 运行 exclave 服务，将敏感组件移出内核的直接访问范围，使单一服务被攻破不再意味着整个内核地址空间失守。Secure Exclaves 正是在这一方向上把音视频处理等能力隔离到独立安全环境的延伸。

**「影响」** 对系统与安全工程师而言，这意味着音视频原始数据不再默认暴露给主系统，隐私指示器也从软件约定升级为硬件验证的强制约束；但相关能力目前仅见于 HomeView 与 iPhone 18 Pro，其他设备是否跟进尚不明确。
