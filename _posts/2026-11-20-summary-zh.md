### [PHP 流包装器大小写漏洞静默关闭 TLS](https://x.com/ljachowicz/status/2123477025268924514) ⭐️ 8.0/10

PHP 的 HTTP/FTP 流包装器在识别 URL scheme 时不区分大小写，但仅在第五个字符为小写 s 时才启用 TLS，导致 HTTPS://、httpS://、FTPS:// 等写法被当作明文 HTTP/FTP 发送。令牌、Basic 认证、Cookie、POST 请求体和 FTP 登录信息因此以明文传输，被第三方重定向到此类地址时同样受影响。该问题编号为 CVE-2026-128064（GHSA-f6gg-rchx-xw8j），CVSS 4.0 评分 8.2，已在 PHP 8.2.36、8.3.37、8.4.28、8.5.13 和 8.6.0 中修复。8.1 及更早版本已 EOL，不会获得修复，用户只能自行将 URL 的 scheme 统一转为小写。

telegram · zaihuapd · 11月20日 11:04

**「背景」** PHP 的流包装器让 fopen、file\_get\_contents 等函数可以直接通过 http://、https://、ftp:// 等 scheme 访问远程资源，是许多库和脚本发起网络请求的底层机制。URL scheme 按规范本应大小写不敏感，但该实现把 TLS 的启用条件绑定在小写字母 s 上，使大小写差异产生了安全后果。

**「影响」** 使用受影响 PHP 版本、且 URL 可能来自用户输入或重定向的部署，可能在不知情下以明文泄露凭据和请求数据，需升级到已修复版本或强制将 scheme 转为小写。

### [OpenAI 推出后台模式：长任务异步执行，token 最高省 40%](https://developers.openai.com/api/docs/guides/background) ⭐️ 7.0/10

OpenAI 上线后台模式，将长耗时 API 请求改为异步执行：开发者需在请求中设置 background: true，并通过 background\_options.completion\_window 选择 2 小时或 8 小时的完成时限，对应 token 费率分别比标准价低 30% 和 40%；若不设置则使用默认的 soonest，不享受折扣。该折扣目前处于公测阶段，覆盖 GPT-6.2 Astra、GPT-6.2 Sol、GPT-6.1 Terra 和 GPT-6 Luna 等模型。此外，后台模式会临时存储响应数据，即使 store 设为 false 或启用零数据保留也不例外。上述信息来自二手来源的简要转述，模型名称与具体条款尚无法从现有材料独立核实。

telegram · zaihuapd · 11月20日 19:15

**「背景」** OpenAI 的 Responses API 支持后台模式，开发者可在请求中设置 background: true，将耗时较长的任务转为异步执行，并通过 background\_options.completion\_window 指定完成时限。官方文档说明，后台模式会临时存储响应数据，即使 store 设为 false 或启用零数据保留也不例外，这些数据用于执行请求并供结果检索，且所有完成时限下的临时存储内容均会加密。OpenAI 社区帖子称，2h 与 8h 完成窗口的折扣目前处于公开测试阶段，适用于 GPT-6.2 Astra 和 GPT-6.2 Sol 等模型。

**「影响」** 对需要运行长耗时任务的开发者而言，该模式提供了以更长完成时限换取最高 40% token 成本节省的选项，但需接受响应数据被临时存储这一与零数据保留设置相冲突的条件。
