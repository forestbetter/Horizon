### [DeepSeek 与清华发布 DSec 沙箱平台技术报告](https://arxiv.org/abs/2609.22978) ⭐️ 8.0/10

DeepSeek-AI 与清华大学联合发布技术报告《DeepSeek Elastic Compute（DSec）》，公开了支撑大规模 Agent 训练与评测的沙箱基础设施。DSec 通过统一 SDK 提供 FnCall、容器、Firecracker microVM 和完整 VM 四种后端，覆盖 OJ 判题、软件工程、安全渗透、电脑操作等负载，并与强化学习框架协同，将有状态的 rollout 执行与可抢占的 GPU 训练解耦。规模上，单个生产单元约 160 个节点，每天服务约 300 万个沙箱实例，峰值并发超 38 万，创建速度超每秒 5000 个，单节点可承载 3200 个容器或 800 个 microVM。平台基于 3FS 分布式文件系统按需加载 EROFS 镜像，相比传统 Docker 全量拉取，任务完成时间快 1.7 倍、磁盘写入减少 57%，内存共享与回收机制使峰值内存占用下降约 40%。

telegram · zaihuapd · 9月22日 12:45

**「背景」** 智能体训练与评测需要在隔离环境中反复执行代码和操作任务，沙箱的创建速度、并发密度与资源开销直接影响训练吞吐。传统容器方案通常依赖 Docker 全量拉取镜像，启动慢且磁盘写入高，难以支撑强化学习场景下大规模、短生命周期的 rollout 需求。

**「影响」** 该报告为大规模智能体训练提供了可参考的生产级沙箱架构与量化指标，对关注 AI 系统与基础设施的开发者具有直接借鉴价值；不过相关性能数据来自 DeepSeek 自身生产环境，向其他负载迁移时仍需验证。

### [Cloudflare Python Workers 正式全面可用](https://blog.cloudflare.com/python-workers-ga/) ⭐️ 7.0/10

Cloudflare 于 9 月 21 日宣布 Python Workers 正式全面可用（GA），Python 由此成为其开发者平台的一级支持语言，可无缝接入 Workers AI、R2、D1 等服务。该功能在两年前推出，如今原生支持 FastAPI、Django、Flask 等框架，并新增底层网络能力，可在其中直接运行 PostgreSQL 等数据库以及 LangChain 等 AI 库。

telegram · zaihuapd · 9月22日 12:00

**「背景」** Cloudflare Workers 是 Cloudflare 的无服务器边缘计算平台，开发者可在其全球网络上运行代码，最初以 JavaScript/TypeScript 为主要语言。Python Workers 于两年前推出，此前处于测试阶段，目标是在边缘环境中让 Python 包和框架“开箱即用”。此次 GA 意味着 Python 从实验性支持升级为平台的一级语言，与 Workers AI、R2、D1 等服务的原生绑定同步落地。

**「影响」** 对使用 Cloudflare Workers 的 Python 开发者而言，现在可以直接在边缘运行 FastAPI、Django、Flask 等框架，并原生调用 Workers AI、R2、D1 及 PostgreSQL、LangChain，无需再借助 JavaScript 胶水代码。本地开发与部署需改用 pywrangler CLI，并预先安装 uv 与 Node。

### [美国提议与中方建立 AI 事件通报渠道](https://x.com/rohanpaul_ai/status/2102254209597157548) ⭐️ 7.0/10

美国在 9 月 20 日纽约会谈中向中方提议建立人工智能事件通报渠道，用于通报达到国家安全门槛的 AI 相关事件，美国财长贝塞特称此举旨在提高两国间的透明度。双方还计划围绕共同风险建立定期的美中 AI 对话。据中方官方声明，双方确认讨论了 AI 相关议题，但未明确表示接受美方这一具体机制。目前该提议尚未成为双边协议或条约。

telegram · zaihuapd · 9月22日 14:48

**「背景」** 美中在人工智能治理领域的沟通机制长期缺乏制度化安排，两国在 AI 安全、出口管制等问题上立场分歧明显。此次提议出现在 9 月 20 日纽约会谈期间，由美国财长贝塞特对外披露，属于两国在更广泛经贸与安全对话框架下探讨 AI 议题的一部分。所谓“事件通报渠道”指一方在发生可能触及国家安全门槛的 AI 相关事件时向另一方通报，目前仅停留在提议阶段，尚未形成双边协议或条约。

**「影响」** 若该机制最终落地，涉及美中两国 AI 系统、且达到国家安全门槛的事件将可能被纳入双边通报范围，相关企业需关注未来可能出现的披露或合规要求。不过目前这仅是美方提议，中方未确认接受，也未形成协议或条约，实际约束力与适用范围仍不确定。
