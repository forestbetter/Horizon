### [数据中心建设遇两党阻力，2028 年美国扩建面临政策风险](https://newsletter.semianalysis.com/p/the-datacenter-backlash-goes-bipartisan) ⭐️ 6.0/10

一篇行业通讯文章指出，两党都在主张对数据中心实施更严格的规则，其中得克萨斯州可能长期冻结许可审批，被视为 2028 年美国数据中心建设最大的单一风险；文章称 2027 年的建设计划已基本确定，但未给出冻结范围或受影响企业的具体数据。

rss · Semianalysis · 11月2日 02:40

**「背景」** 该简报称，2027 年的数据中心建设基本已经确定，2028 年则不那么有保障，并称得克萨斯州长期暂停发放许可目前是美国数据中心建设面临的最大单一风险。简报未说明冻结的范围、持续时间或受影响企业。

**「影响」** 若德州暂停电网接入的举措长期化，在建或规划中的数据中心项目将面临延期，因为数据中心从审批到投运通常只需 12 至 36 个月，而新建高压输电线路的选址、审批和建设需 5 至 15 年。据 Enkon Energy Advisors，德州州长已于 8 月 3 日冻结新的电网接入，等待审计结果。

### [LongCat-2.5 发布：1.6 万亿参数原生多模态模型](https://longcat.ai/blog/longcat-2.5/) ⭐️ 8.0/10

LongCat 团队发布 LongCat-2.5，这是一款面向长程 agent 任务的原生多模态模型，总参数 1.6 万亿，每个 token 激活约 480 亿参数。该模型在 LongCat-2.0 基础上强化了视觉理解与 agentic coding 能力，并将视觉信号编码为多级离散 token，与文本统一处理，可完成视觉编程等任务。目前官网已可试用并接入 API，但 GitHub 与 HuggingFace 版本尚未开放，也尚无独立评测数据。

telegram · zaihuapd · 11月2日 11:08

**「背景」** LongCat-2.5 是 LongCat 团队在 LongCat-2.0 基础上推出的原生多模态模型，采用混合专家（MoE）架构，总参数 1.6 万亿、每 token 激活约 480 亿，通过大规模长上下文训练与长程强化学习提升复杂工程开发和视觉编程能力。据第三方资料，LongCat-2.5-Preview 于 2026 年 9 月 25 日上线 LongCat API 平台并提供网页与 API 访问，正式版于 11 月 1 日发布、11 月 2 日在 API 平台全面可用；该时间线未在官方博文中得到确认。

**「影响」** 对需要长程 agent 与视觉编程能力的开发者而言，LongCat-2.5 目前只能通过官网试用和 API 接入，GitHub 与 HuggingFace 权重尚未开放，因此无法本地部署或自行微调。
