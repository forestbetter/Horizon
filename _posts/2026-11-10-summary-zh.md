一份泄露的草案显示，欧盟《数字公平法案》拟限制成瘾性设计与订阅陷阱。草案要求数字企业允许用户关闭自动播放、连续使用奖励等诱导强迫或过度使用的功能；在线订阅须提供取消按钮、续费提醒和人工客服，并在免费试用转为付费订阅前取得用户明确同意。草案还禁止面向未成年人的游戏付费抽奖、“付费获胜”和画像广告，并要求游戏虚拟货币标明真实币值。欧盟委员会定于 11 月 11 日提交该法案，同时改革消费者保护合作框架，违规企业最高可被处以全球营业额 6%的罚款；两项提案均需欧洲议会与欧盟各国政府同意才能生效。

telegram · zaihuapd · 11月10日 00:42

**「背景」** 《数字公平法案》是欧盟委员会计划提出的一项立法，旨在更新面向在线服务的消费者保护规则，预计与《消费者保护合作条例》的修订一同纳入 11 月 11 日的“消费者一揽子计划”。据 Euronews 看到的草案，该法案拟直接禁止十类操纵性网站和应用设计，例如虚假的库存告急提示、预勾选附加项和反复弹出的催促窗口。该法案仍需欧洲议会与欧盟各国政府批准才能生效。

**「潜在影响」** 若草案按现有条款通过，面向欧盟用户的游戏与订阅类数字企业将需调整抽奖机制、未成年人付费设计及游戏内货币定价展示，并可能面临最高全球营业额 6%的罚款；但该法案仍属泄露草案，须经欧洲议会与成员国同意方能生效，实际约束时间尚不确定。

### [Claude Code 配置致 2539 个真实凭据泄露](https://www.ithome.com/1/024/888.htm) ⭐️ 7.0/10

安全公司 Apiiro 发现，1,994 个 GitHub 代码库中暴露了 2,539 个真实凭据，涉及数据库密码、API Token 等敏感信息。问题根源在于 Claude Code 会把获准执行的 Shell 命令写入本地设置文件，当这些文件未被 Git 忽略时，就会随项目一起提交到公共仓库。调查显示，超过 10 万份 Claude Code 本地设置文件被上传至公共仓库，其中约 1,100 份包含机密数据。Claude Code 团队表示正在研究预防措施，并考虑内置密钥扫描功能。

telegram · zaihuapd · 11月10日 19:20

**「背景」** Claude Code 是 Anthropic 推出的 AI 编程工具，可在终端中协助开发者执行命令和修改代码。为减少重复确认，它会把用户批准执行的 Shell 命令写入本地设置文件；当这些文件未被 .gitignore 排除时，就会随项目一起提交到 GitHub。Apiiro 的调查显示，此类配置文件中可能包含数据库密码、API Token、云密钥和 SSH 登录信息，从而形成公开泄露。

**「影响」** 使用 Claude Code 且未将本地设置文件加入 .gitignore 的开发者，可能在不知情的情况下把数据库密码、API Token 等真实凭据推送到公开仓库，Apiiro 已在 1,994 个仓库中确认 2,539 个真实凭据。Claude Code 团队表示正在研究预防措施，并考虑内置密钥扫描功能，但当前版本尚未提供自动清理。
