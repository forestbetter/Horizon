### [美团开源 LongCat-2.5 智能体模型，称全程未用英伟达 GPU](https://the-decoder.com/meituan-releases-a-1-6-trillion-parameter-agent-model-that-never-touched-an-nvidia-gpu/) ⭐️ 8.0/10

美团 LongCat 团队在模型正式发布一周后公布了 LongCat-2.5 的权重，该模型专为自主完成冗长、多步骤任务（尤其是编程任务）的智能体而设计。官方称其训练全程使用中国芯片（华为升腾加速卡），未使用英伟达 GPU。模型每个 token 激活约 480 亿参数，支持文本、图像和视频输入，权重以 MIT 许可证发布并可商用。在 Terminal Bench v2.1 上得分为 88.4，略低于 Claude Opus 5 的 89.1。

telegram · zaihuapd · 11月15日 19:08

**「背景」** 美团是一家中国科技公司，主要运营本地生活服务平台，业务涵盖外卖、到店服务与消费点评、酒店旅行预订以及即时零售。华为升腾是华为自研的 AI 加速芯片系列，常被视为英伟达 GPU 在中国市场的替代方案之一。LongCat-2.5 是美团 LongCat 团队发布的智能体模型，官方称其训练全程使用华为升腾加速卡。

**「影响」** 对开发者而言，LongCat-2.5 以 MIT 许可证发布且可商用，并配套提供 W4A4 量化版本，使模型能在国产 AI 加速卡上以原生 INT4 计算运行，从而降低了在非英伟达硬件上部署大型智能体模型的门槛。不过，“全程未使用英伟达 GPU 训练”目前仅为官方说法，尚缺乏独立验证。

### [阿里发布 Qwen4-Max 旗舰模型，后续将开源小模型](https://mp.weixin.qq.com/s/pJUt0xwD6H-WMyzd8TjZaQ) ⭐️ 8.0/10

阿里通义千问团队正式推出新一代旗舰模型 Qwen4-Max，采用全新稀疏 MoE 架构，总参数达 2.4 万亿，原生支持视觉理解与百万 Token 长上下文。官方称其在编程、办公及长程任务执行上表现亮眼，前端编程能力在 Code Arena 盲测中位居全球前列。成本方面，单个任务平均费用从 26.58 元降至 11.16 元，降幅近 58%，Token 消耗减少近 50%，API 定价同步下调。该模型已正式上线，团队透露后续将推出规模更小的 Qwen4 系列模型并公开模型权重。上述性能与成本数据均来自官方宣传，尚无独立验证或详细技术说明。

telegram · zaihuapd · 11月16日 10:52

**「背景」** Qwen4-Max 是阿里通义千问 Qwen 系列的最新旗舰模型，建立在全新的 Qwen4 架构之上，其 2.4 万亿参数规模延续了此前 Qwen3.8-Max 已达到的参数体量。据 Qwen 官方博客，团队此前曾提前发布 Qwen3.8-Flash-Next 的架构改动，供社区在全量 Qwen4 系列构建前先行审视，并称 Qwen3.8-Max 是首次开源 Max 级模型权重的尝试。稀疏 MoE（混合专家）架构通过按需激活部分专家来控制大参数模型的推理成本，这也是理解本次成本下降与后续小模型开源计划的关键背景。

**「影响」** 对开发者而言，Qwen4-Max 单任务平均费用从 26.58 元降至 11.16 元、Token 消耗减少近 50% 且 API 定价同步下调，意味着在编程、办公和长程任务场景中可显著降低调用成本；团队还表示后续将推出更小的 Qwen4 系列模型并公开权重，这将影响依赖开源权重的本地部署与二次开发用户。

### [华为云 MaaS 上线开源盘古模型 openPangu-2.1-Pro](https://mp.weixin.qq.com/s/8JfFmscBTDl_mPQMycD8Nw) ⭐️ 7.0/10

11 月 15 日，华为云 MaaS 模型即服务平台正式上线开源盘古模型 openPangu-2.1-Pro，围绕 Agent 开发、AI 编码和推理优化三大方向升级能力。该模型基于 10 万余条专项数据优化 Skills 触发与工具调用，重点适配鸿蒙 ArkTS 开发与升腾算子生成，并接入智果 AgentArts、码道 CodeArts、果办 OfficeAce 等产品。定价方面，推理输入为 0.8 元/百万 tokens，推理输出为 3.2 元/百万 tokens，缓存命中输入为 0.016 元/百万 tokens。该消息为简短的产品公告，未披露模型规模、许可证细节、基准测试成绩或第三方评测结果，实际能力尚待验证。

telegram · zaihuapd · 11月16日 00:03

**「背景」** 盘古是华为自研的大模型系列，此前主要通过华为云以闭源服务形式提供。MaaS（模型即服务）是云厂商按调用量计费、直接提供模型推理能力的平台模式，用户无需自行部署模型。此次以“openPangu”名义上线开源版本，意味着华为在开源大模型生态中进一步布局，但该公告未披露模型参数规模、开源许可证及基准测试结果。

**「影响」** 对鸿蒙 ArkTS 开发者和升腾算子开发者而言，该模型在华为云 MaaS 上提供了按 token 计费、可直接调用的开源盘古选项，并已接入 AgentArts、CodeArts、OfficeAce 等产品；但公告未披露模型规模、许可证与基准测试结果，实际能力与开源可用范围仍待验证。

### [腾讯混元发布 Hy4 flash：224B 参数、1M 上下文](https://mp.weixin.qq.com/s/5yBbf-ctYziM5r0i6Y17lA) ⭐️ 7.0/10

腾讯混元发布 Hy4 flash，总参数 224B、激活参数 12B，支持多模态与 1M 上下文，官方称综合效果略优于 Hy4 preview。API 定价为每百万 Token 输入 0.5 元、输出 2 元，命中缓存时仅 0.02 元，较 Hy4 大幅下降。官方称 WorkIndex 单任务成本为 Hy4 preview 的 1/13、Hy4 的 1/20。该模型已在腾讯云 TokenHub、WorkBuddy 和元宝上线，并计划开源；11 月 30 日前 WorkBuddy 限免、API 五折。上述效果与成本数据均来自厂商，尚待第三方验证。

telegram · zaihuapd · 11月16日 15:17

**「背景」** MoE（混合专家）架构通过让每个 token 只激活部分参数来降低推理成本，因此模型常以“总参数/激活参数”两个数字标注规模。腾讯混元此前已推出 Hy4 与 Hy4 preview，本次 Hy4 flash 是在同一系列上主打日常任务性价比的版本。

**「影响」** 对需要处理长上下文、多模态日常任务的开发者而言，Hy4 flash 的 API 定价（每百万 Token 输入 0.5 元、输出 2 元，缓存命中 0.02 元）和官方所称的单任务成本优势，可能显著降低高频调用场景的支出；但上述效果与成本数据均为腾讯单方说法，且模型尚未开源，实际表现仍待验证。
